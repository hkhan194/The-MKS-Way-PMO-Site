Start a project

Know if it is a project.

If the work changes how people, teams, systems, or processes work, treat it as a project.

Do this next

  • Check if the work is a project.
  • Name the sponsor and project manager.
  • Complete the project brief.

Is this a project?

If most answers are yes, treat it as a project.

  • Does it have a clear goal?
  • Does it have an end point?
  • Does more than one person or team need to help?
  • Will it change how something works?
  • Is there risk, cost, compliance, or stakeholder impact?

Project size checker

SizeSimple definition
SmallLow risk, short duration, one team.
MediumCross-functional, some risk, more planning needed.
LargeFirm-wide, high risk, regulatory or senior stakeholder impact.

If in doubt, classify up. It is easier to reduce control later than fix a missed risk.

Before you start

  • Project or normal work: a project changes something. Normal repeat work stays with the team that owns it.
  • Name the owners: the sponsor owns the outcome. The project manager owns delivery.
  • Complete the brief: explain the change, why it matters, owners, first risks, and next step.
