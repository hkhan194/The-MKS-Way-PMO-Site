Start a project

Check if the work is a project or BAU.

If the work changes how people, teams, systems, or processes work, treat it as a project.

Check if the work is a project or BAU

Project: a piece of work with a clear goal, a clear finish, and a change to how something works.

BAU: repeat work that keeps an existing service running day to day.

Use this quick test before you submit

1Start with the idea

Write down what is changing.

2Ask the 5 questions
  • Is there a clear goal?
  • Is there a clear end point?
  • Does it need more than one person or team?
  • Will it change how people, systems, or processes work?
  • Is there risk, cost, compliance, or stakeholder impact?
3Mostly yes?

Treat it as a project.

TopicPlain meaningSimple example
ProjectTemporary work that changes something and needs coordination.Moving a team to a new system or changing a firm-wide process.
BAUOngoing work that keeps a service running day to day.Monthly reporting, routine onboarding, or standard support tasks.
SmallLow risk, short duration, one team.One team changing one local process.
MediumCross-functional, some risk, more planning needed.Two or more teams changing how work flows.
LargeFirm-wide, high risk, regulatory or senior stakeholder impact.Firm-wide or regulated change.
