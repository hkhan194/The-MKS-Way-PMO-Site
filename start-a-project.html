Start a project

Know if it is a project.

If the work changes how people, teams, systems, or processes work, treat it as a project.

Do this next

1. Check the idea

Use the project test.

2. Name the owners

Choose the sponsor and project manager.

3. Open the form

Submit the new project proposal form.

Use this quick test

1New piece of work

Something is changing.

2Ask 5 questions
  • Is there a clear goal?
  • Is there a clear end point?
  • Does it need more than one person or team?
  • Will it change how people, systems, or processes work?
  • Is there risk, cost, compliance, or stakeholder impact?
3Mostly yes?

Treat it as a project.

Yes

Name the sponsor and project manager, then open the proposal form.

No

Keep it with the owning team as business-as-usual work.

Project size checker

SizeSimple definitionExample
SmallLow risk, short duration, one team.Updating one local process inside one department.
MediumCross-functional, some risk, more planning needed.Rolling out a new workflow across Finance and HR.
LargeFirm-wide, high risk, regulatory or senior stakeholder impact.Replacing a core system or delivering a firm-wide regulatory change.

If in doubt, classify up. It is easier to reduce control later than fix a missed risk.
