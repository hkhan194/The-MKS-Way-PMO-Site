PMO help and reference

Ask early.

PMO is here to help you get projects clear, controlled, and finished properly.

I need help with...

  • Ask PMO: get advice, setup support, or a second pair of eyes.
  • Learn: find short guidance for roles, stages, RAID, and reporting.
  • Find a template: use the right file at the right point in the project.
  • Reference material: use the guide, glossary, and version history when needed.

Contact PMO when

  • You are not sure if something is a project.
  • Ownership is unclear.
  • Sponsor support is weak.
  • The project is Amber or Red.
  • Templates or governance are unclear.

Useful files

  • PMO Support Request
  • Project Brief
  • RAID Log
Need more detail?
  • Glossary: RAID means risks, assumptions, issues, and dependencies. RAG means Red, Amber, Green.
  • Version history: keep a simple record of what changed, when, and who approved it.
  • Full reference library: use the full delivery guide when you need the background detail. Open full delivery guide
